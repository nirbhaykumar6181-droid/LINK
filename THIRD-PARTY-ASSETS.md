# Third-party asset and license notes

This package intentionally excludes the Cokenvat Demo OTF font provided for the development build. The included font package's readme says personal use only; commercial use requires permission/license from the creator.

The frontend currently references Google Fonts remotely (Manrope and decorative font families). Review each font's license and Google's current terms, and assess privacy/offline requirements. Replace or self-host only after confirming the applicable licenses.

The Node dependency `web-push` is declared in `package.json`; review its license and dependencies using the package registry/audit process at the time of transfer.

This note is not a complete legal clearance. Buyer/seller should inventory and verify all third-party materials before commercialization.
